大家好，这是一个语音日历工具。
不同于传统的日历应用——你不需要手动填表单，不需要记住事件名称，
只需要像跟助理说话一样，说出你想做的事情。
我演示几个场景。

## 场景一：一句话添加多个事件（30秒）

```
（点击麦克风按钮）

"添加下午五点的需求评审会，还有七点的客户见面会。"

（安静等待 2 秒——录音自动停止）

系统自动识别出这是两个独立事件。
先弹出第一个确认卡片——需求评审会，下午五点。
确认没问题，点击"确认创建"。

（点击确认）

立刻弹出第二个——客户见面会，晚上七点。
再确认。

（点击确认）

两个事件都已创建，右侧日历自动更新。一句话，两个事件，完成。
```

---

## 场景二：静音自动停止（15秒）

```
注意刚才的流程——我说话结束后没有手动点击停止按钮。
系统检测到我停顿了 2 秒，自动结束了录音。
这就是"不打断"的交互体验。
麦克风旁边的小圆点在你说话时会跳动，安静下来就停住了。
```

---

## 场景三：按时间模糊删除（20秒）

```
现在我想删除下午两点的那个会议——
但我不需要记住它叫"产品评审"。

（点击麦克风）

"删除今天下午两点的会议。"

（等待自动停止）

系统自动匹配到"产品评审"（下午两点），直接删除了。
不需要说出精确的事件名称，描述时间就够了。
```

---

## 场景四：语音编辑事件（25秒）

```
刚才删掉了产品评审，现在我重新加一个，然后演示怎么修改它。

（口述或用文字输入 "添加明天上午十点的产品评审"）

（确认创建）

"把产品评审改到明天下午三点。"

系统找到"产品评审"，时间从上午十点改到下午三点。
右侧视图自动跳到对应日期。
```

---

## 场景五：语音查询（25秒）

```
接下来是查询能力。

（点击麦克风）

"下周有什么安排？"

自动切换到周视图。

再试一个。

"查找产品相关的安排。"

系统按关键词过滤，显示出所有包含"产品"的事件。

还可以问"这个月有什么安排"、"明天有事吗"——
系统会自动切到对应的日、周、月视图。
```

---

## 场景六：冲突检测 + 空闲推荐（30秒）

```
现在演示一个很实用的功能。

当前 5 月 31 号已经有下午两点的产品评审。
如果我尝试在同样的时间段再加一个事件——

（输入 "添加今天下午两点半的临时会议"）

确认卡片顶部出现了红色冲突警告：
"时间冲突 — 与'产品评审'(14:00-15:30)重叠"

同时下方有一个提示：
"建议改为 15:30（当天首个空闲时段）"

点击这个建议，时间自动跳到 15:30，冲突解除。
这个功能帮你避免日程打架。
```

## 场景七：年历导航 + 事件详情（20秒）

```
最后看两个界面细节。

（鼠标移到左上角 "2026年5月" 标题）

点击月份标题，展开全年 12 个月的网格。
有事件的月份带小圆点标记。点击任意月份直接跳转。

（点击右侧一个事件卡片）

点击事件卡片，弹出详情编辑对话框。
可以修改标题、日期、时间、备注、提醒。
底部有快捷时间调整按钮——加 15 分钟、减半小时、加一小时。
修改完点击保存。

（关闭弹窗）
```

## 结尾（15秒）

```
这就是语音日历。

核心思路是：用自然语言交互替代繁琐的表单操作。
添加、删除、编辑、查询——全部用说话完成。

项目基于 Next.js，语音转写用通义千问 DashScope，
指令解析用 DeepSeek，前端完全开源。

谢谢观看。
